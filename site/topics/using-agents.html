Using AI Agents

A chatbot answers one question. An agent works toward a goal: it plans steps, uses tools, reads the results, and adjusts. This page is about using agents well, as a user, before you ever build one.

What makes it an agent

Three ingredients turn a model into an agent:

  1. A goal, not just a question. "Book me the cheapest flight" instead of "what are flight prices."
  2. Tools it can call: web search, a calendar, a code runner, a database.
  3. A loop: think, act, observe the result, repeat until the goal is done or it gets stuck.

If the system cannot take actions and see what happened, it is a chatbot with extra steps, not an agent.

When agents are worth it

Agents shine on multi-step tasks where the steps depend on each other: researching a topic across sources, triaging a support inbox, or refactoring code across files. They are overkill for single questions. "Summarize this paragraph" does not need an agent; it needs one model call.

Decision rule

If you can write down the exact steps in advance, write a script. If the steps depend on what you find along the way, use an agent. If it is one question, just ask the model.

Prompting patterns that work

Agents respond to structure. Four patterns cover most use:

1. Give the goal, the constraints, and the finish line

Example

Weak: "Research EV pricing." Strong: "Goal: compare total cost of ownership for three EVs under $40k. Constraints: US pricing, 2026 models, include insurance estimates. Finish when you have a table with all three and a one-paragraph recommendation." The agent now knows what done looks like.

2. Show, do not just tell

One short example of the output format beats three paragraphs of description. "Format the result exactly like this: ..." followed by a two-line sample.

3. Break big goals into checkpoints

"First find the three candidates and stop. I will pick one before you continue." Checkpoints keep long agent runs from drifting, and they let you correct course cheaply.

4. Tell it what to do when stuck

"If a source is paywalled, skip it and note that you skipped it. If two sources conflict, report both. Never invent a number." Agents guess when they lack instructions for failure. Write the failure instructions.

Supervising an agent

Think of the agent as a fast intern, not an oracle. Skim its intermediate steps, not just the final answer. The moment you see it going down a wrong path, stop it and redirect; a correction at step 2 saves twenty wasted steps. And keep the safety habits from the AI Safety page: approve irreversible actions yourself, and check anything that will be sent to another human.

Try it today

Pick one real multi-step task from your week, something like "find three options for X and compare them." Write the goal, constraints, and finish line as above, add one checkpoint, and run it. Compare the result to doing it yourself. You will learn more from one real run than from ten articles about agents.
